📊 CÁCH HOẠT ĐỘNG
=================================================================

FORK GỐC (Original):
  fork() → Copy ALL pages → Chậm, lãng phí
  
COW FORK:
  fork() → Share pages, mark read-only + COW
  read  → OK (dùng chung page)
  write → Page fault → Copy page → OK
  
RESULT: 10-100x faster fork, 50-90% less memory!

=================================================================
✨ KEY CHANGES
=================================================================

1. Reference Counting (kalloc.c):
   - Track bao nhiêu processes share mỗi page
   - kfree() chỉ free khi ref count = 0

2. COW Flag (riscv.h):
   - PTE_COW = 1L << 8 (RSW bit)
   - Mark pages là COW

3. Modified uvmcopy() (vm.c):
   - KHÔNG copy pages
   - Chỉ share + mark COW
   - 100x faster!

4. New cowcopy() (vm.c):
   - Handle page fault khi write
   - Allocate + copy khi CẦN
   - Lazy evaluation

5. Page Fault Handler (trap.c):
   - Detect scause == 15 (store fault)
   - Call cowcopy()
   - Retry instruction
